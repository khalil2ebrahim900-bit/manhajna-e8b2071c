# الخطة

سأحوّل الكود الذي أرسلته ليشتغل داخل الموقع الحالي بدل وضعه كصفحة HTML منفصلة، حتى يبقى تسجيل الدخول والمساعد الذكي والاختبارات شغّالة.

## ما سيتم تغييره
- تحديث صفحة الدخول لتستخدم نفس فكرة الكود: الاسم، المرحلة، الجنس، ثم الدخول.
- إضافة خيار المرحلة السادسة بجانب الأول والثاني والثالث الإعدادي إذا كان النظام الحالي يسمح بذلك.
- إضافة قسم «إنجازاتي» يعرض عدد الاختبارات، الأسئلة المجابة، والإجابات الصحيحة.
- ربط بطاقات الصفحة الرئيسية: الاختبارات، منهجنا AI، إنجازاتي، والمنهج الكامل.
- الحفاظ على تصميم «منهجنا» الحالي الزجاجي الهادئ بدل نسخ CSS قديم داخل الصفحة.

## ملاحظات مهمة
- لن أضع الكود كملف HTML خام، لأن الموقع مبني كتطبيق متصل بتسجيل دخول وذكاء اصطناعي.
- سأحافظ على المساعد الذكي الحالي بدل `/api/ask` الموجود في الكود، لأنه جاهز ويعمل داخل الموقع.
- إذا كانت قاعدة البيانات الحالية تقبل الصفوف 7 و8 و9 فقط، سأطابق «الأول/الثاني/الثالث إعدادي» معها، وأتعامل مع «السادس ابتدائي» كخيار يحتاج توسيع بيانات إن أردت لاحقاً.
